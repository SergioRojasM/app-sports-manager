# Brand Identity

GRIT Arena representa la evolución del entrenamiento deportivo mediante tecnología.

La marca transmite:

- Disciplina
- Rendimiento
- Superación
- Comunidad
- Evolución

El estilo visual combina **Sport Tech**, **Performance** y **Premium SaaS**.

La experiencia debe sentirse:

- moderna
- limpia
- tecnológica
- rápida
- enfocada
- competitiva

Nunca debe parecer infantil, gamer o futurista exagerado.

---

# Visual Style

La identidad se construye sobre un entorno oscuro con acentos turquesa.

Principios:

- Dark Mode First
- Mucho contraste
- Grandes áreas negativas
- Fotografía deportiva cinematográfica
- Interfaces minimalistas
- Brillos muy sutiles
- Líneas finas para dividir contenido
- Uso estratégico del color primario

Todo comunica precisión.

---

# Color Philosophy

## Fondo

El fondo siempre debe ser azul casi negro.

No utilizar negro puro.

Los fondos pueden contener:

- degradados muy suaves
- iluminación lateral
- humo
- partículas
- texturas deportivas

Nunca deben competir con el contenido.

---

## Color Primario

El turquesa representa:

- progreso
- evolución
- energía
- tecnología

Debe utilizarse para:

- botones principales
- palabras destacadas
- iconografía
- enlaces
- indicadores
- elementos activos

Nunca colorear grandes bloques de texto.

---

## Blanco

El blanco comunica claridad.

Debe utilizarse para:

- títulos
- logotipo
- contenido principal

---

# Photography

Las imágenes deben seguir estas reglas.

## Atletas reales

Preferentemente:

- corredores
- nadadores
- ciclistas
- equipos
- entrenadores

No utilizar fotografías posadas.

Las personas deben estar realizando esfuerzo físico.

---

## Tratamiento

Todas las fotografías deben tener:

- baja saturación
- alto contraste
- dominante azul
- sombras profundas
- iluminación dramática

El color turquesa únicamente aparece como iluminación ambiental o gráficos.

Nunca modificar el color de piel.

---

## Composición

Las fotografías siempre dejan espacio para texto.

Utilizar:

- desenfoque
- humo
- viñetas
- overlays oscuros

para mejorar la legibilidad.

---

# Layout

Sistema de 12 columnas.

Contenido máximo:

1280 px

Espaciados amplios.

Mucho aire entre secciones.

Las composiciones deben sentirse limpias.

---

# Typography

## Rajdhani Bold Italic

Uso exclusivo para:

- Hero
- títulos
- números grandes
- estadísticas
- llamadas de atención

Siempre en mayúsculas cuando sea navegación o botones.

---

## Montserrat

Uso para:

- párrafos
- descripción
- formularios
- tablas
- interfaces

Debe mantener excelente legibilidad.

---

# Buttons

## Primary

- fondo turquesa
- texto oscuro
- radio 8px
- sin sombra pesada

Hover

- ligeramente más brillante

---

## Secondary

- transparente
- borde turquesa
- texto turquesa

Hover

- fondo turquesa al 10%

---

# Cards

Las tarjetas utilizan:

- fondo ligeramente más claro
- borde de 1px
- divisores finos

Nunca sombras fuertes.

La profundidad se consigue mediante contraste tonal.

---

# Icons

Los iconos son:

- lineales
- 1.5px
- simples
- geométricos

Representan conceptos como:

- disciplina
- rendimiento
- comunidad
- enfoque
- evolución

Siempre en color turquesa.

---

# Hero Sections

Toda portada debe incluir:

- fondo deportivo cinematográfico
- overlay oscuro
- iluminación lateral
- gran titular
- una palabra resaltada en turquesa
- CTA principal
- CTA secundario
- beneficios rápidos debajo

La composición debe mantener una lectura inmediata.

---

# Illustration Style

Cuando existan gráficos o elementos decorativos:

- líneas diagonales
- transparencias
- degradados suaves
- efectos de velocidad
- formas geométricas

Nunca usar ilustraciones caricaturescas.

---

# Branding Rules

El logotipo siempre debe respetar su área de seguridad.

No:

- deformar
- cambiar colores
- agregar sombras
- aplicar efectos 3D
- rotarlo

Las versiones permitidas son:

- color sobre fondo oscuro
- monocromático oscuro
- monocromático blanco

---

# Motion

Las animaciones deben ser discretas.

Duración:

150–300 ms

Utilizar:

- Fade
- Slide
- Scale suave

Nunca rebotes exagerados.

---

# UI Principles

Cada pantalla debe comunicar:

1. Rendimiento
2. Claridad
3. Tecnología
4. Profesionalismo
5. Evolución

El usuario debe sentir que está utilizando una plataforma para atletas de alto rendimiento, no una aplicación deportiva tradicional.
